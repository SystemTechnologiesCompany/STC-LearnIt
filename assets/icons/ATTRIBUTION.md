STC LearnIt local icon set

These small SVG icons were drawn for this project in a simple rounded line-art style. They are original local assets, not downloaded copies of Lucide artwork. Lucide was consulted as a visual reference for a consistent, lightweight icon style; its library is ISC licensed: https://github.com/lucide-icons/lucide/blob/main/LICENSE

Icons use `currentColor` so the website can theme them for light and dark modes.
